# Glossário | v1.0
| Termo | Significado |
|---|---|
| Fábrica de Negócios | Nome de trabalho do produto de inteligência consultiva e execução adaptativa |
| Orquestrador | Coordena objetivos, especialistas, ferramentas e estado |
| Agente | Especialista configurado com identidade, competência, missão e limites |
| KAIROS | Especialista de projetos, produtos e processos; PM AI Partner nesta iniciativa |
| SIA | Storyboard Intelligence Architect; estrutura narrativas e entendimento |
| BPMN Master Architect | Especialista em modelagem de processos |
| Status Report Executive Architect | Especialista em relatórios executivos |
| JEV | Jury of Expert Validators; avaliação independente obrigatória dos entregáveis, composição adaptativa |
| QA/homologação | Verificação técnica e funcional com testes e evidências; distinta de aceite humano |
| MCP | Model Context Protocol; conectividade com ferramentas e recursos |
| LLM | Modelo de linguagem |
| Multi-LLM | Capacidade de utilizar diferentes modelos/fornecedores conforme política |
| Skills | Competências/metodologias especializadas versionadas |
| Agent Registry | Catálogo de agentes, nome conceitual |
| Agent Factory | Constituição excepcional de agente temporário, nome conceitual |
| Memory Manager | Curadoria, persistência e recuperação de conhecimento, nome conceitual |
| RAG | Recuperação de conhecimento para contextualizar geração |
| BPMN | Business Process Model and Notation |
| Commander | Produto de gestão de projetos existente, não dependência obrigatória |
| Access Management Service | Produto de governança de acesso existente, fora da integração inicial |
| PoC | Prova de conceito de viabilidade |
| MVP | Primeira versão funcional utilizável, com escopo restrito |
| Discovery | Investigação de problema, necessidades, objetivos e contexto |
| Artefato | Resultado concreto: documento, diagrama, código ou aplicação |
| Baseline | Versão de referência controlada |
| Gate | Critério impeditivo de passagem |
